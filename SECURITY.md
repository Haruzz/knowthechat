# Security policy

## Supported version

Only the current `main` branch and the production deployment at
`knowthechat.com` receive security fixes.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature in the Security tab of
this repository. It creates a private security advisory visible only to the
reporter and repository maintainers.

Include:

- The affected route, component, or commit.
- Reproduction steps or a minimal proof of concept.
- The likely impact.
- Any suggested mitigation.

Do not include real credentials, non-public chat archives, or personal data in
the report. Please allow a reasonable period for investigation and remediation
before public disclosure.

For abuse, privacy, or content-removal requests that are not security defects,
open a repository issue without reproducing the content in question.
